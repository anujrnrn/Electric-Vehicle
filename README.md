This dashboard aims to assess the growth trends, technological advancements (range and efficiency), and geographic distribution of the EV market, encompassing both Battery Electric Vehicle (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
The Project involved critical data cleaning and transformation steps using Power Quwry and Dax.
The Project dashboard was structured to present mandatory Key Performance Indicators (KPIs) and analytical views across two interactive screens (a main dashboard and a detail page), connected by page navigation buttons to ensure smooth, user-friendly exprience.
